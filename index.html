MÓDULO 1

¿Qué es una variable aleatoria?

Es una función matemática que asigna un valor numérico real a cada resultado posible del espacio muestral de un experimento aleatorio.

🎲

¿Por qué se llama aleatoria?

Porque el valor exacto que tomará no se conoce antes de realizar el experimento. Sin embargo, sí podemos conocer sus posibles valores y la distribución de probabilidades asociada.

🔎

Idea clave

Una variable aleatoria traduce resultados de un experimento aleatorio a números, permitiendo analizarlos matemáticamente.

DISCRETA

Se obtiene al contar

Sus valores posibles son finitos o numerables.

  • Cantidad de clientes por hora.
  • Número de caras al lanzar tres monedas.
  • Cantidad de pedidos de delivery.
X ∈ {0, 1, 2, 3, …}
CONTINUA

Se obtiene al medir

Puede tomar cualquier valor dentro de un intervalo real.

  • Tiempo de resolución de un examen.
  • Masa o peso de un producto.
  • Tiempo de respuesta de un servidor.
Y ∈ (0, ∞)
ACTIVIDAD RÁPIDA

MÓDULO 2

Variables aleatorias discretas

En una variable discreta, la probabilidad puede asignarse a valores puntuales y luego acumularse.

FUNCIÓN DE PROBABILIDAD
p(x) = P(X = x)

Asigna a cada valor posible de X la probabilidad exacta de que ocurra.

0 ≤ P(X = x) ≤ 1
Σ P(X = x) = 1
FUNCIÓN ACUMULATIVA
F(x) = P(X ≤ x)

Suma las probabilidades correspondientes a los valores menores o iguales que x.

0 ≤ F(x) ≤ 1
F(a) ≤ F(b), si a ≤ b

MÓDULO 3

Variables aleatorias continuas

Una variable continua puede tomar infinitos valores dentro de un intervalo. La probabilidad se interpreta como un área bajo una curva de densidad.

FUNCIÓN DE DENSIDAD
P(a ≤ X ≤ b) = ∫ab f(x) dx

El valor de f(x) en un punto no representa directamente una probabilidad.

f(x) ≥ 0
∫ f(x) dx = 1
P(X = x) = 0
x f(x)

Densidad → Área → Probabilidad

EJEMPLO APLICADO

Tiempo de respuesta de un servidor web

Sea X el tiempo de respuesta del servidor en milisegundos, con valores entre 0 y 4. La función de densidad es:

f(x) = x/8   para 0 ≤ x ≤ 4;   0 en otro caso.
Queremos calcular P(X ≤ 2)
P(X ≤ 2) = ∫02 x/8 dx = 0,25

Interpretación: existe un 25 % de probabilidad de que el servidor responda en 2 milisegundos o menos.

MÓDULO 4

Características de las variables aleatorias

Estas medidas permiten analizar el valor esperado, la dispersión y la relación entre variables.

01

Esperanza

Representa el valor promedio teórico esperado a largo plazo.

E(X) = Σ xᵢP(X = xᵢ)
Valor esperado
02

Varianza

Mide cuánto se dispersan los valores respecto de la esperanza.

Var(X) = E[(X − μ)²]
Dispersión
03

Desvío estándar

Es la raíz cuadrada de la varianza y conserva las unidades originales.

σ = √Var(X)
Dispersión
04

Covarianza

Permite estudiar cómo varían conjuntamente dos variables.

Cov(X,Y) = E[(X−E(X))(Y−E(Y))]
Relación
05

Correlación

Mide la dirección y la intensidad de la relación lineal.

ρ = Cov(X,Y)/(σXσY)
−1 ≤ ρ ≤ 1

# Valores posibles de la variable
x <- c(0, 1, 2, 3)

# Función de probabilidad
prob_puntual <- c(0.10, 0.40, 0.35, 0.15)

# Función de distribución acumulativa
prob_acumulada <- cumsum(prob_puntual)

# Tabla
tabla_distribucion <- data.frame(
  X = x,
  "P(X=x)" = prob_puntual,
  "F(x)=P(X<=x)" = prob_acumulada
)

print(tabla_distribucion)
# Función de densidad
densidad <- function(x) {
  ifelse(x >= 0 & x <= 4, x / 8, 0)
}

# Calcular P(X <= 2)
probabilidad <- integrate(
  densidad,
  lower = 0,
  upper = 2
)

resultado_prob <- probabilidad$value
resultado_prob
# Datos
horas <- c(1, 2, 3, 4, 5)
notas <- c(4, 5, 7, 8, 10)

n <- length(horas)

# Esperanza / media
media_horas <- mean(horas)
media_notas <- mean(notas)

# Varianza dividiendo por n
var_horas <- sum((horas - media_horas)^2) / n
var_notas <- sum((notas - media_notas)^2) / n

# Desvío estándar
desvio_horas <- sqrt(var_horas)
desvio_notas <- sqrt(var_notas)

# Covarianza
covarianza <- sum(
  (horas - media_horas) *
  (notas - media_notas)
) / n

# Correlación
correlacion <- covarianza /
  (desvio_horas * desvio_notas)
